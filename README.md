# ML Lab Project

Replication of **"A Comparative Study of ML and DL Models for Heart Disease Classification"**  
Simanjuntak, Robet & Hoki, *JAIC 9(6)*, 2025.

## Run order

> **Note:** TensorFlow DNN results are not bit-reproducible across hardware/library versions. The numbers in `results_heart/` were produced on a specific machine and are the graded results.

### 1. Install dependencies

**Windows:**
```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
cd frontend && npm install
```

**macOS/Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cd frontend && npm install
```

### 2. Exploratory data analysis

```bash
python eda_heart.py
```

Outputs: `eda_dist.png`, `eda_corr.png`

### 3. Replicate the paper (slow – trains 6 models × 5 seeds)

```bash
python replicate_heart.py
```

Outputs: `results_heart/raw.csv`, `summary.csv`, `comparison.csv`, `best_params.csv`, `dnn_curve_seed{42..46}.csv`

### 4. Generate figures

```bash
python make_figures.py
```

Outputs: `figs/*.png`

### 5. Export JSON for the frontend

```bash
python export_results.py
```

Outputs: `frontend/public/data/*.json`

### 6. Run the frontend (dev)

**Windows:**
```bat
cd frontend
npm run dev
```

**macOS/Linux:**
```bash
cd frontend
npm run dev
```

Open: http://localhost:5173

### 7. (Optional) Start the live-prediction API

```bash
# From project root – trains models on seed-42 split first
cd frontend && npm run api
```

Or directly:
```bash
python -m uvicorn api.main:app --reload --port 8000
```

The frontend dev server proxies `/api` to `http://127.0.0.1:8000`.

## Project layout

```
ml-lab-project/
├── heart.csv               Kaggle Heart Failure Prediction dataset (918 rows)
├── eda_heart.py            Quick EDA + matplotlib figures
├── replicate_heart.py      Main replication script (NB/DT/RF/SVM/LR/DNN)
├── make_figures.py         Publication-ready matplotlib figures
├── paper_results.py        Single source of truth for paper's reported numbers
├── export_results.py       Reads results_heart/ → writes frontend/public/data/*.json
├── requirements.txt
├── results_heart/          Graded results (DO NOT re-run replicate_heart.py)
├── figs/                   Matplotlib figures
├── api/                    FastAPI live predictor
│   ├── main.py
│   └── train_models.py
└── frontend/               Vite + React 18 + TypeScript dashboard
    ├── public/data/        Static JSON (generated by export_results.py)
    └── src/
```

## Academic integrity

This project uses Google Antigravity to build the web interface. All reported numbers are produced by the project's own Python scripts.
